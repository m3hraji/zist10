# زیستیار دهم (ZistYar 10)
سامانه هوشمند و جامع آموزش زیست‌شناسی ۱ پایه دهم (رشته علوم تجربی) بر اساس کتاب درسی مصوب.

## نحوه انتشار رایگان در GitHub Pages:
۱. این فایل‌ها را داخل مخزن GitHub خود با نام `zist10` (در آدرس https://github.com/M3hraji/zist10) آپلود یا Commit و Push کنید.
۲. وارد صفحه مخزن در گیت‌هاب شوید و روی تب **Settings** کلیک کنید.
۳. در منوی سمت چپ بخش **Pages** را انتخاب کنید.
۴. در بخش **Build and deployment**، گزینه **Source** را روی **Deploy from a branch** قرار دهید.
۵. شاخه (Branch) را روی **main** و پوشه را روی **/ (root)** بگذارید و روی دکمه **Save** کلیک کنید.
۶. پس از حدود ۲ دقیقه، وبسایت شما در آدرس زیر آنلاین و در دسترس جهانی خواهد بود:
👉 **https://m3hraji.github.io/zist10/**

طراحی شده با عشق به علم برای دانش‌آموزان کوشای پایه دهم ایران.
